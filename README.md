## 研究テーマ

**多様な学習者要求に対応するオンデマンド講義メディア生成**

PDF形式の講義スライドを入力として、学習者の要求に応じた講義メディアを自動生成する研究に取り組んでいます。  
学習者の違いを「難易度」「詳細度」「提示形態」の3軸で整理し、LLMによるスライド解析・台本生成、文書画像解析による領域抽出、テキスト音声変換、動画生成を組み合わせています。

### 主な技術要素

- LLMを用いたスライド構造解析・台本生成
- 文書画像解析による文字・図表・数式領域の抽出
- 台本文とスライド領域の対応付け
- 音声長に合わせたハイライト同期
- Python / OpenAI API / MoviePy / PyMuPDF / ffmpeg

## 開発経験

### 講義メディア自動生成システム

PDFスライドから、台本・音声・ハイライト付き動画を自動生成する研究用システムを開発しています。  
単にスライドを読み上げるのではなく、講義全体の流れを解析し、学習者に合わせた説明を生成する点を重視しています。

### 研究室内購買管理アプリ

研究室内の購入履歴、在庫、支払い状況を一元管理するWebアプリを開発しました。  
利用者と管理者双方の課題を整理し、Slack BotやクラウドDBを組み合わせて、実際に研究室内で運用できる形を目指しました。

使用技術: TypeScript / React / Next.js / Supabase / PostgreSQL / Slack Bot / Vercel
